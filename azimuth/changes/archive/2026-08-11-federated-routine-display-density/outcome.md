# Outcome: federated-routine-display-density

Status: accepted

## Departures

The first physical split put every accepted model package in backend. A cold agent could infer that
display density was routine but could not name its exact area or model source from the experience
checkout. The materializer now moves `experience/**` intent and this change history to
`rides-experience`; the singular catalog remains in `rides-assurance` and each checkout carries a
small reference to it.

The first repository reference was machine-correct but operationally awkward. A second cold agent
treated the catalog locator as shell-relative and had no installed `azimuth` command. The lab now
states that reference locators are reference-file-relative and supplies a repository-local wrapper.
A fresh agent then found `experience-intent`, `rider-experience`, the routine obligations and the
complete-workset boundary without a corrective prompt.

An adversarial review found that several propositions were enforced only by caller order or happy
paths. Finalization now rederives and checks the model; untracked and ignored model inputs fail;
receipt subjects are exact closed-world sets; repository-owned paths cannot escape their checkout;
and assembly rederives the most-specific area mount rather than trusting the producer.

No browser unit-test framework was introduced for this small preference. The production build and
type checker exercise integration with React and Next, while persistence behavior remains ordinary
routine implementation rather than Azimuth covering evidence.

## Residual decisions

The active cross-repository change has a singular authority by policy, but the federation schema
does not yet detect duplicate active proposals. Duplicate accepted spec authority does fail. The
experiment therefore leaves F7 open instead of presenting a policy as a machine invariant.

Changing an area id cannot pass as a locator-only move because existing source identities stop
resolving. The tool does not yet demand a particular archived topology-migration artifact, so F6 is
supported at the identity boundary only.

Repository manifests remain trusted CI statements about the semantics of tracked sources. Digests,
revision checks and containment prevent substitution and escape; they cannot prove that a malicious
extractor described a symbol honestly.

The density spec intentionally leaves default choice, unavailable storage, cross-tab propagation
and pre-hydration presentation unspecified. Escalate and refine the intent if the preference begins
to affect accessibility or information visibility.
