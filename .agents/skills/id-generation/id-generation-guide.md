# ID Generation Implementation Guide

Complete implementation guide for IdGen and Crockford Base32 ID encoding in drim-dev.

## ID Generation with IdGen

### IdStructure Breakdown

```csharp
new IdStructure(52, 8, 3)
// 52 bits: Timestamp (milliseconds since epoch) - ~142 years
//  8 bits: Generator ID (worker/host identifier) - 256 different servers
//  3 bits: Sequence (incremented within same ms) - 8 IDs/ms per generator
// Total: 63 bits (fits in long)
```

### Registration in Program.cs

```csharp
using IdGen;
using IdGen.DependencyInjection;

// Program.cs
```

### IdFactory Implementation

```csharp
// Common/Web/Identification/IdFactory.cs
using IdGen;
using IdGen.DependencyInjection;
using Microsoft.Extensions.DependencyInjection;

namespace Common.Web.Identification;

public class IdFactory
{
    private readonly IdGenerator _idGenerator;

    public IdFactory(IdGenerator idGenerator)
    {
        _idGenerator = idGenerator;
    }

    public long Create() => _idGenerator.CreateId();
}

public static class IdGeneratorExtensions
{
    public static IServiceCollection AddIdFactory(this IServiceCollection services, int generatorId)
    {
        services.AddIdGen(generatorId, () => new IdGeneratorOptions
        {
            IdStructure = new IdStructure(52, 8, 3),
        });

        services.AddSingleton<IdFactory>();

        return services;
    }
}
```

## Usage in Vertical Slices

### Creating Entities

```csharp
// Features/Skills/CreateSkill.cs
public class Handler : IRequestHandler<Request, long>
{
    private readonly AppDbContext _db;
    private readonly IdFactory _idFactory;

    public Handler(AppDbContext db, IdFactory idFactory)
    {
        _db = db;
        _idFactory = idFactory;
    }

    public async Task<long> Handle(Request request, CancellationToken ct)
    {
        // Check for duplicate slug
        var slugExists = await _db.Skills
            .AnyAsync(x => x.Slug == request.Slug, ct);

        if (slugExists)
            throw new ConflictException($"Skill with slug '{request.Slug}' already exists");

        // Create skill with generated ID
        var skill = new Skill
        {
            Id = _idFactory.Create(),         // Generate time-based ID
            Slug = request.Slug,
            Title = request.Title,
            Description = request.Description,
            Content = request.Content,
            AuthorId = request.CurrentUserId,
            IsPublished = false,              // Requires admin approval
            CreatedAt = DateTime.UtcNow,
            UpdatedAt = DateTime.UtcNow
        };

        await _db.Skills.AddAsync(skill, ct);
        await _db.SaveChangesAsync(ct);

        return skill.Id;
    }
}
```

### Foreign Key Relationships (Use Long IDs)

```csharp
// Features/Skills/StartLearningSkill.cs
public class Handler : IRequestHandler<Request>
{
    private readonly AppDbContext _db;
    private readonly IdFactory _idFactory;

    public Handler(AppDbContext db, IdFactory idFactory)
    {
        _db = db;
        _idFactory = idFactory;
    }

    public async Task Handle(Request request, CancellationToken ct)
    {
        // Find skill by slug
        var skill = await _db.Skills
            .FirstOrDefaultAsync(x => x.Slug == request.Slug && x.IsPublished, ct);

        if (skill == null)
            throw new NotFoundException("Skill not found");

        // Create relationship using long IDs
        var userSkill = new UserSkill
        {
            Id = _idFactory.Create(),         // Generate ID for junction table
            UserId = request.UserId,          // Long ID (FK)
            SkillId = skill.Id,               // Long ID (FK)
            StartedAt = DateTime.UtcNow,
            CreatedAt = DateTime.UtcNow,
            UpdatedAt = DateTime.UtcNow
        };

        await _db.UserSkills.AddAsync(userSkill, ct);
        await _db.SaveChangesAsync(ct);
    }
}
```

## ID Encoding for Public APIs

### Crockford Base32 Overview

**Created by Douglas Crockford** - A human-friendly encoding scheme designed for transmitting numbers accurately between humans and computers.

**Design Goals:**

- ✅ **Human and machine readable** - Easy for both to process
- ✅ **Compact** - More efficient than decimal (5 bits per character)
- ✅ **Error resistant** - Difficult to make typing mistakes
- ✅ **Pronounceable** - Can be transmitted verbally
- ✅ **URL-safe** - No special characters
- ✅ **Case-insensitive** - Accepts both upper/lowercase on decode

**Character Set:** `0123456789abcdefghjkmnpqrstvwxyz` (32 symbols)

**Excluded letters:** I, L, O, U

- I and L confused with 1
- O confused with 0
- U excluded to avoid accidental obscenity

**Decoding flexibility:** Treats `i`/`l` as `1`, `o` as `0`, ignores hyphens

### IdEncoding Implementation

```csharp
// Common/Web/Identification/IdEncoding.cs
using Common.Web.Utils;
using SimpleBase;

namespace Common.Web.Identification;

public static class IdEncoding
{
    /// <summary>
    /// Encodes a long ID to Crockford Base32 with checksum (lowercase).
    /// Example: 123456789012345 → "3g5w7x9y1z2a"
    /// </summary>
    public static string Encode(long id)
    {
        Span<byte> bytes = BitConverter.GetBytes(id);
        Span<byte> bytesWithChecksum = new byte[bytes.Length + 1];
        bytes.CopyTo(bytesWithChecksum);
        bytesWithChecksum[^1] = bytes.CalculateChecksum();
        return Base32.Crockford.Encode(bytesWithChecksum).ToLower();
    }

    /// <summary>
    /// Decodes a Crockford Base32 encoded ID with checksum validation.
    /// Returns false if the ID is invalid or checksum fails.
    /// </summary>
    public static bool TryDecode(string? encodedId, out long id)
    {
        id = default;

        if (string.IsNullOrWhiteSpace(encodedId))
        {
            return false;
        }

        byte[] bytesWithChecksum;
        try
        {
            bytesWithChecksum = Base32.Crockford.Decode(encodedId);
        }
        catch
        {
            return false;
        }

        var bytes = bytesWithChecksum.AsSpan()[..^1];
        var checksum = bytesWithChecksum[^1];
        var calculatedChecksum = bytes.CalculateChecksum();
        if (checksum != calculatedChecksum)
        {
            return false;
        }

        id = BitConverter.ToInt64(bytes);
        return true;
    }
}
```

### Checksum Calculation

```csharp
// Common/Web/Utils/ChecksumExtensions.cs
namespace Common.Web.Utils;

public static class ChecksumExtensions
{
    /// <summary>
    /// Calculates a simple XOR checksum for byte array.
    /// Used to detect transmission errors in encoded IDs.
    /// </summary>
    public static byte CalculateChecksum(this Span<byte> bytes)
    {
        byte checksum = 0;
        foreach (var b in bytes)
        {
            checksum ^= b;
        }
        return checksum;
    }
}
```

```csharp
// Response DTO
public record SkillResponse(
    string Id,      // Encoded ID for public API
    string Slug,
    string Title,
    string Description)
{
    public static SkillResponse FromEntity(Skill skill)
    {
        return new SkillResponse(
            IdEncoding.Encode(skill.Id),    // Encode long ID to Crockford Base32
            skill.Slug,
            skill.Title,
            skill.Description);
    }
}

public async Task<SkillResponse> Handle(Request request, CancellationToken ct)
{

}
```

```json
    {
```

```csharp
            [FromRoute] string encodedId,
            ISender sender,
            CancellationToken ct) =>

            if (!IdEncoding.TryDecode(encodedId, out var userId))

            var result = await sender.Send(request, ct);
            return Results.Ok(result);
        });
    }
}
```

### When to Use Encoded vs Raw IDs

**Use Encoded IDs (Crockford Base32):**

- ✅ Public API responses (JSON)
- ✅ URLs where ID is exposed (`/api/users/{encodedId}`)
- ✅ Client-facing interfaces
- ✅ Anywhere JavaScript consumes IDs

**Use Raw Long IDs:**

- ✅ Database operations (primary keys, foreign keys)
- ✅ Internal handler logic
- ✅ Backend-to-backend communication
- ✅ Database queries and relationships

**Prefer Slugs Over IDs:**

- ✅ Content entity URLs (`/api/skills/{slug}` not `/api/skills/{id}`)
- ✅ SEO-friendly routes
- ✅ Human-readable URLs

```json
{
  "IdGenerator": {
    "GeneratorId": 0
  }
}
```

```json

  }

```

**For Multiple Production Servers:**

- Server 1: GeneratorId = 1
- Server 2: GeneratorId = 2
- Server 3: GeneratorId = 3
- etc. (up to 256 servers)

## Troubleshooting

### Issue: Duplicate IDs

**Cause:** Two servers using the same generator ID

**Solution:** Ensure each server has a unique generator ID in configuration

### Issue: IDs are not sequential

**Expected:** IDs are roughly time-ordered, not strictly sequential

**Explanation:** Multiple servers generate IDs concurrently, sequence resets each millisecond

### Issue: JavaScript precision loss

**Cause:** JavaScript's 53-bit safe integer limit

**Solution:** Always return IDs as strings in JSON responses
