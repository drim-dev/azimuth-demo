# Manual charter: payment status on the rider receipt

This is a procedure, not evidence that the procedure ran.

Against the immutable release candidate:

1. Open pending, captured and declined receipts at narrow and wide viewport sizes.
2. Navigate each receipt using only the keyboard.
3. Read each state with a screen reader and confirm the live region announces a changed state.
4. Disable color and confirm the state remains distinguishable.
5. Ask the tester to state what, if anything, the rider must do in each state.

An execution receipt must name the build, environment, executor, instant, outcome and findings.
Until such a receipt exists, this charter contributes no Azimuth evidence.
